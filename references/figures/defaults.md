# 可覆盖的绘图默认值

以下为此技能的工作偏好，不是 GRF 官方规定。用户明确请求优先，其次是当前项目 AGENTS.md，再采用本文件默认值。无需为了使用默认值反复征求确认。

| 设置 | 默认值 |
|---|---|
| 编辑范围 | 既有图局部修改，保留未涉及设计和其他幻灯片 |
| PDF 页面 | 修改后同步导出第 1 页图 PDF |
| 不透明照片 | 按 PDF 页面实际放置尺寸，约 450 ppi，JPEG 质量参数 75；不放大低分辨率素材 |
| 线稿、Logo、细密图案 | 保留原像素与无损编码 |
| 透明照片 | 按 PDF 实际放置尺寸约 450 ppi；仅降采样、不放大；RGB 与 alpha 保持无损编码及对应关系 |
| 透明线稿、Logo、细密图案 | 保留原像素、透明度与无损编码 |
| 上传上限 | 按项目平台限制检查并留余量；多文件同时上传时报告合计，不假定平台有统一上限 |
| 文字、箭头和几何图形 | PPTX 中可编辑，PDF 中保留矢量 |
| 风格 | 继承现有设计；新图柔和配色，白色内部圆角框无深色描边 |
| 字体 | 英文优先 Times New Roman；中文使用实际可用且匹配源稿的 CJK 字体 |
| 临时产物 | 复用项目 `.work/figure-editing/` 下任务目录 |
| 申请书构建 | 默认不编译 TeX、不更新整份申请书 PDF |

PPTX 与原素材保持原质量。导出后的实际图片参数和局部视觉检查是交付依据；默认值不是导出器已经实现这些能力的承诺。
