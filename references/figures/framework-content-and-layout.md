# Framework content and example layout

Read when checking a framework against its source document, arranging parallel examples, or extending comparison panels.

## Semantic consistency

- Check headings, categories, example membership and scope against the current source document. Distinguish source terminology from proposed shorthand; absence of an exact phrase does not by itself establish a conceptual mismatch.
- Use parallel categories at a consistent level of abstraction. Distinguish organizational groupings used for display from formal categories defined in the source.
- Make captions describe the visible evidence and preserve the intended sequence, dependency or relationship. Visual balance cannot compensate for incorrect grouping or labeling.
- Complete confirmed edits while keeping unresolved conceptual questions separate. Do not silently restore content deliberately removed by the author.

## Correspondence and comparison

- For panels intended to correspond, check example coverage, ordering and captions across both sides after additions or removals. Do not impose one-to-one matching when the figure communicates a different mapping.
- Match reading direction, row structure, arrow placement and caption position across comparable panels. Equal outer dimensions alone do not ensure consistent structure.
- In a controlled comparison, preserve unrelated content and presentation while changing the intended variable. Category-level illustrations may use different examples when that supports the intended explanation.
- Remove thumbnails, labels or duplicate baseline states that add no information, then rebalance the remaining content.

## Evidence and assets

- Make source assets, intermediate states and final results visually distinguishable. Show each at the appropriate stage of the process rather than substituting a later-stage result for its source.
- Select crops that make the claimed property visible while retaining enough context to interpret it. In paired detail views, show corresponding regions at comparable scales.
- When extending an existing illustration, use the relevant reference and preserve unrelated visual attributes. Inspect the specific feature being changed, not merely overall resemblance.
- Keep generated conceptual illustrations distinct from experimental evidence in project notes. Record the reference, prompt, asset and intended use; retain editable text and geometry in the figure.
- For ordered parameter variations, a central baseline with variants on both sides can clarify progression. Use it only when the parameter and ordering support that reading; align any highlight with the intended state.

## Space and hierarchy

- Distinguish category boundaries from internal subgroup boundaries, using consistent styles at each level. Match approved exemplars rather than assigning fixed line styles to all figures; omit unnecessary separators.
- Allocate width by content density, visible object sizes and label lengths. Reclaim excess whitespace in neighboring panels before shrinking a crowded comparison.
- Preserve aspect ratios and compare visible content bounds, not only image rectangles. Use consistent object scale or visible height where the comparison requires it; align meaningful edges or baselines.
- Keep equivalent viewports equal when requested, while allowing proportional padding inside them. Check clearance between content, captions and dividers, and avoid unintended cropping.
- Inspect at readable resolution and intended output scale for missing examples, misleading labels, inconsistent apparent scale, crowding, excess whitespace and misaligned emphasis. A successful export is not a visual check.
