# 官方指南来源与版本

- [GRF 官方入口](https://www.ugc.edu.hk/eng/rgc/funding_opport/grf/)
- [年度征集通知](https://www.ugc.edu.hk/eng/rgc/funding_opport/share/grfecs_call_letter.html)
- [UGC 版权说明](https://www.ugc.edu.hk/eng/ugc/important.html)

这些入口可能更新，不能当作固定年度存档。先确定用户申请年度，再读取其提供的对应年度官方文件；缺少文件时从官方入口查找，记录标题、年度、修订版本、来源链接和查阅日期。无法核实的条款标为待核实，继续完成不依赖这些条款的写作或论证评审。

完整英文指南和中文译文不随公开包分发。用户可在项目中保存自备指南并提供路径；不要自动复制到技能仓库。非官方中文译文只作辅助，歧义以官方英文原文为准。

[历史版本摘要](grf-guidance-snapshot.md) 仅用于导航，不能替代完整条款或证明其他年度的最新要求。
